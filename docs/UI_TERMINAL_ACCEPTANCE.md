## 每个组合的操作与通过标准

下面每项须在三种组合分别填写结果；未执行项保持待验收。

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 编辑与输入法 | 中文组词、候选确认、换行、粘贴多行，选择 `/cd` 目录补全 | 候选确认不会误发消息，文字无丢失；目录候选只回填 |
| 队列 | 回答生成中 Enter 进入下回合队列，Alt+Enter 立即进入当前回合；按 Ctrl+G 打开选择器，↑↓ 选择后 Enter 取回单条、Delete/Ctrl+D 删除单条（需确认）、Ctrl+R 取回全部；再测试 Esc 取消 | 队列类型正确；选择器上下键、取回与删除互不串扰；被消费的消息不会误取；取回/取消保留文本，无重复或幽灵消息；记录被宿主拦截的快捷键 |
| 审批 | 触发可审批工具请求，分别允许、拒绝、允许本会话同类，测试 `/revoke` | 弹窗可见且焦点正确；拒绝不执行，同类授权可撤销 |
| 复制 | 鼠标拖选文本后松开，直接到外部编辑器粘贴；再测试 Ctrl-C、Ctrl+Shift+C 和 `/copy` | 松开即复制；行尾无渲染填充，代码缩进保留，提示显示非空白字符数；单击/空白选择不覆盖剪贴板；无选中时 Ctrl-C 符合 `/hotkeys` |
| 流式与长会话 | 生成含标题、代码块、中文的长回答；滚动、缩放窗口、点击工具块及 Ctrl+O | 最终回答不重复，排版重算正确，滚动与输入持续响应 |
| 会话边界 | `/new`、`/rename`、`/find`、`/resume`、`/fork`；运行任务时尝试切换会话或 `/cd` | 空闲时恢复正确；忙碌时阻止切换，旧扫描结果不覆盖当前会话 |
| 归档与删除 | 归档测试会话并恢复，再归档后测试删除短语错误/取消/正确三条路径 | 仅正确确认后删除选中测试会话；取消不改数据 |
| checkpoint | 创建快照后修改测试文件，分别取消预览、制造外部改动冲突、显式强制恢复 | 取消不改文件，普通恢复拒绝冲突，显式强制后文件与会话历史一致 |
| 退出恢复 | 空闲时 Ctrl-Q 退出，重启后在审批/流式时退出，再检查 shell 输入与光标 | 无挂起审批或残留工作进程，终端光标、回显和输入恢复 |
